# Vault

A store of saved secrets, addresses, cards, and similar details that bots can use for a task when the user allows it.

**Add-on.** The core already seals fxbot's own keys, and [plugins](../_completed/phases/plugins.md) will seal each add-on's settings. A store of the owner's own details is for owners who want one, as an add-on, like [1Password](1password.md).

Not planned yet.
