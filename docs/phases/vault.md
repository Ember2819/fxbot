# Vault

A store of saved secrets, addresses, cards, and similar details that bots can use for a task when the user allows it.

**Plugin.** The core already seals fxbot's own keys, and [plugins](../_completed/phases/plugins.md) will seal each plugin's settings. A store of the owner's own details is for owners who want one, as a plugin, like [1Password](1password.md).

Not planned yet.
