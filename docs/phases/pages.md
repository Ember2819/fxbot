# Pages

Pages a bot writes for reading outside the live chat, such as a report, a guide, or a summary of a project. The [library](../_completed/phases/library.md) keeps each page as an item of kind `page`, tagged with the bot and session that wrote it.

**Add-on.** A plugin with a tool bots write pages with, and a screen to read them, through the [plugin API](plugins.md).

Not planned yet.
