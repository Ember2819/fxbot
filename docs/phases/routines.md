# Bot routines

A bot runs a saved task on a schedule, such as a morning summary, without anyone opening the chat.

**Add-on.** A plugin that keeps saved tasks in its own table, gives bots tools to make them, and starts each task's turn on time. Starting a turn is part of the [plugin API](plugins.md), which [triggers](triggers.md) and [cross-bot messaging](cross-bot-messaging.md) use too.
