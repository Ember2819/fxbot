# herdr screen

A herdr button next to Settings replaces the screen with the [herdr](https://herdr.dev) interface, to work with everything herdr runs. A status bar along the bottom of the app switches back to bot mode.

**Plugin.** Part of a herdr [plugin](../_completed/phases/plugins.md), which adds the button and the screen through the plugin API. The core never names herdr. fxbot's first herdr plugin, which gave bots herdr's agents as tools, left in 0.4.1, to be planned again.
