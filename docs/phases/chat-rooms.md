# Chat rooms

Rooms where more than one bot can take part in the same conversation.

**Add-on.** A plugin that adds rooms to the app: a sidebar entry and a screen for each room, its own tables for rooms and who is in them, and a hook that hands each message to the room's bots and starts their turns, all through the [plugin API](plugins.md).

It is one of the two plugins that prove the plugin API, planned in [plugins: the first plugins](plugins.md#the-first-plugins).
