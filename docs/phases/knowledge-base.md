# Knowledge base

A knowledge base the bots can draw on. Storage is undecided, and the current lean is blob storage plus a vector store.

**Add-on.** Not every bot needs one, and it brings its own storage. The core already keeps files in the [library](../_completed/phases/library.md), and will keep [memories](../_completed/phases/memories.md). A knowledge base or knowledge graph is an MCP server or plugin over its own store, not a core migration.

Not planned yet.
