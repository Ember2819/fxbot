fxbot v0.5.0 is out!

https://fxbot.sh/docs/reference/changelog/

Before upgrading: the update restarts the database once, with your data. On Docker, a start takes about a minute until your next update, and always below Docker 25. If setup.sh stopped on your machine, run it again.

Changes:

- New Plugin: Dreams => Each night your bot goes over its day and keeps what it learned as memories and skills, with Undo
- New Plugin: Fresh => /fresh starts a chat over from a summary, pointed at where you want to go next
- New Plugin: Chat Rooms Computer => Give a chat room a computer its bots share, taking turns
- Plugin directory added: browse plugins at https://fxbot.sh/plugins/
- Every plugin now gets its own generated icon
- Default bot: pick one and fxbot opens to its chat on launch
- Settings split into tabs, and plugins can add their own
- Plugins show a one-line description in Installed and Browse
- Installer now detects your podman, docker, and compose versions and sets up what's missing, so older setups work
- Bug fix: fxbot runs on Docker again
- Bug fix: stopping takes 30s at most, so a stuck reply can't hang shutdown
