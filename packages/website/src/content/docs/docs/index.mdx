fxbot is your bot, built and configured how you want it. It starts with a lean, fast core, works with local models as well as hosted ones, and grows with the [plugins](/docs/explanation/core-and-plugins/) you pick. You run it on a machine of your own, and open it there, or from your phone and other devices: Tailscale is the recommended way in, and [other ways](/docs/how-to/reach-it/) work too.

New to it? Start with the tutorial, [Your first fxbot](/docs/tutorials/first-fxbot/), or [ask your AI agent to set it up](/docs/tutorials/set-up-with-an-agent/). The docs are in four parts, each for a different need.
